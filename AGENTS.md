# Agent Guidelines

## Language Policy

All first-party code and documentation in this repository MUST be written in English:

- Comments, docstrings, commit messages, and README/documentation files: English only.
- Identifiers, function/class/file names, test names: English only.
- User-facing strings printed by the tool (prompts, reports, logs): English only.
- Do NOT introduce new Polish text in code or docs. When touching a file that still contains Polish, migrate it to English in the same change.
- Third-party/vendor content is out of scope for this policy.
